# Research Archive

이 디렉터리는 초기 개발기획 단계에서 검토한 리서치 문서를 보관하는 아카이브입니다.

## 문서 성격

- 투자 추천, 매매 권유, 운용 지시, 실거래 가이드가 아닙니다.
- 현재 구현 상태, API 계약, 검증 결과, 운영 기준의 source of truth가 아닙니다.
- Phase 3D 기능 및 검증 문서와 섞지 않고 별도 참고자료로만 유지합니다.
- 문서 내부의 전략, 조건식, 시장 설명은 구현 완료 상태를 의미하지 않습니다.

## 보관 문서

| 파일 | 설명 |
|---|---|
| `trading-system-design-report.md` | 초기 자동매매 보조 시스템 설계 리서치 |
